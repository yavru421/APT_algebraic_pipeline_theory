# APT Dashboard Quick Guide

## 🚀 What is APT (Algebraic Pipeline Theory)?

**APT** transforms complex computational workflows into mathematical equations that are:
- **Explicit**: Every variable (x1, x2, y1, y2) is clearly defined
- **Traceable**: Each step can be audited and reproduced
- **Modular**: Components can be combined algebraically
- **Deterministic**: Same inputs always produce same outputs

## 📱 Your APT Dashboard Features

### 1. **Pipeline Execution**
Enter instructions like:
```
Y = analyze(X_context)
Summarize all markdown files
Take a screenshot and analyze it
Research the latest discoveries
```

### 2. **Algebraic Notation**
Your workflows become math equations:
```
Y_final = m6(m5(m4(m3(m2(m1(X_startup))))))
```
Where:
- **m1**: System initialization & context scanning
- **m2**: UI component construction
- **m3**: Server connection & health checks
- **m4**: Pipeline execution engine
- **m5**: State persistence & history
- **m6**: Status updates & results display

### 3. **Real-time Monitoring**
- ✅ Server connection status
- 📊 Execution traces for every module
- 💾 Persistent chat history and state
- 🔍 Context file discovery and analysis

### 4. **Chat Integration**
- Natural language conversations
- APT pipeline generation from plain English
- Multi-threaded chat sessions
- Automatic state persistence

If you see timeout errors:
1. The server may be processing a complex request
2. Timeouts are now set to 30-45 seconds for complex operations
3. The dashboard will gracefully handle server disconnections
