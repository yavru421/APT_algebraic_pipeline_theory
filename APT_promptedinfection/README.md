# APT Prompted Infection: System Prompts for External Chat Applications

This folder contains APT-formatted system instruction prompts for major chat applications (ChatGPT, Gemini, Claude, etc.), enabling fast, consistent, algebraic pipeline execution in any LLM environment.

## Pipeline Equation
For each app:
- Let x1 = APT methodology core instructions
- Let x2 = system prompt format for target app
- Let x3 = app-specific best practices
- m1 = extract APT core
- m2 = extract app system prompt format
- m3 = synthesize APT-formatted prompt for app
- y1 = m3(m1(x1), m2(x2), x3) = APT-formatted system prompt for app

## Files
- chatgpt_system.md
- gemini_system.md
- claude_system.md

Each file contains a ready-to-use system prompt for the respective app, following APT algebraic pipeline theory.
