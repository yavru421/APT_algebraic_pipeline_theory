# APT Invariance Stress Test: Research Summary

## Overview
This document summarizes the results of a large-scale invariance stress test using the Algebraic Pipeline Theory (APT) methodology. The experiment systematically varied parameters (dimension $d$, instance size $n$, frequency bands $\omega$) across multiple complexity class representatives (SAT, TSP, coloring, subset sum) and recorded the evolution of geometric invariants.

## Methodology
- **Pipeline:** Modular APT pipeline with parameterized modules for Fourier analysis, polytope generation, cross-correlation, invariant search, visualization, and category-theoretic mapping.
- **Parameter Sweep:**
  - $d$: 3, 4, 5
  - $n$: 4, 5, 6
  - $\omega$: [1,2], [1,2,3], [2,3,4]
  - Problems: SAT, TSP, coloring, subset sum
- **Outputs:** For each run, the following were recorded:
  - Fourier coefficients (per band)
  - Polytope structure (vertices, faces)
  - Cross-correlation metrics
  - Invariants: spectral_gap, vertex_degree_invariant
  - Embedding coordinates
  - Category-theoretic morphisms/obstructions
