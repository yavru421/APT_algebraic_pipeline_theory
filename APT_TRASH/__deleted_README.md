# APT Invariance Research Workspace

This workspace contains all data, pipelines, modules, and documentation for the APT invariance stress test and geometric complexity research.

## Organization
- `data/` — Aggregated results, raw outputs, and analysis scripts
- `pipelines/` — All pipeline YAMLs used for parameter sweeps
- `modules/` — All APT modules used in the experiment
- `APT_INVARIANCE_RESEARCH_SUMMARY.md` — Research summary and analysis instructions

## Reproducibility
All experiments are fully reproducible using the provided pipelines and modules. See the summary for analysis instructions.
